Small permission surface

Your folder. Your network. Your rules.

Pocket Server does not include analytics, ads, cloud storage, or remote-control services. It asks Android for access to one chosen folder and serves that folder only while you keep the server running.

  • Password required for every browser session
  • Downloads enabled; uploads off until you allow them
  • Persistent notification with an immediate stop action
  • Signing checksum published beside every APK

Good to know

Designed for trusted home Wi‑Fi

The local web connection uses HTTP, not HTTPS. Do not expose the port to the public internet, and do not reuse an important password.

Useful limits

What Pocket Server is—and isn’t

Can it replace a Raspberry Pi?

For simple file sharing, often yes. It is not a Docker host, a multi-drive NAS, or a good choice for heavy media transcoding.

Can people reach it from the internet?

Not by default, intentionally. Pocket Server is for the local network. Do not forward its port from your router.

Will it keep running with the screen off?

The foreground service and Wi‑Fi lock are designed for that. Some manufacturers still apply aggressive battery controls, so exclude Pocket Server from battery optimization if needed.

Why does Android warn about the APK?

The app is downloaded from GitHub instead of an app store. Confirm the SHA-256 checksum above if you want to verify the file before installing.
