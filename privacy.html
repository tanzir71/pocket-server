Plain-language privacy note

Private by being small.

Pocket Server contains no advertising, analytics, tracking SDK, account system, or cloud service. It serves files directly from the selected Android folder to authenticated browsers that can reach the phone.

Data the app accesses

The app can read files inside the folder you select through Android’s system folder picker. It cannot use that grant to browse unrelated folders. If you enable uploads, authenticated visitors can create files and folders inside the selected folder.

Data the app transmits

File names, directory pages, downloads, uploads, and the access password travel between the phone and the visiting browser over your local network. Nothing is intentionally sent to the app developer or a third-party service.

Network security

The built-in server uses HTTP Basic authentication over unencrypted HTTP. It is intended only for a trusted home LAN. Do not expose port 8080 or the configured replacement port to the public internet. Use a unique Pocket Server password.

Information stored on the phone

The selected folder URI, port, upload preference, and password are stored in the app’s private Android preferences. App backup and device transfer are disabled so those settings are not copied to a cloud backup.

Removing access

Stop the server to end network access immediately. Clear the app’s storage or uninstall it to remove stored settings and Android’s persisted folder permission.
