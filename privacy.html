Plain-language privacy note

Private by being small.

Pocket Server contains no advertising, analytics, tracking SDK, developer-operated account system, or developer-operated cloud service. It serves selected Android folders to authenticated browsers over the routes you enable.

Data the app accesses

Each site can read files inside the folder you select through Android’s system folder picker. A folder grant does not let the app browse unrelated folders. If you enable uploads for a site, authenticated visitors can create files and folders inside that site’s selected folder.

Data the app transmits

File names, directory pages, downloads, uploads, and authorization headers travel between the phone and visiting browsers. Nothing is intentionally sent to the Pocket Server developer. The network providers involved depend on the route you select:

  • LAN: traffic goes directly over the local network using HTTP.
  • Tailscale: the separate Tailscale app carries traffic inside its encrypted network and applies its own account and privacy terms.
  • Cloudflare Tunnel: Cloudflare terminates public HTTPS and carries requests through the outbound tunnel. Cloudflare can process the request and file content under the Cloudflare account holder’s settings and terms.

Network security

The built-in server uses HTTP Basic authentication. LAN URLs are unencrypted and should be used only on a trusted network. Tailscale encrypts traffic between approved tailnet devices. Cloudflare provides public HTTPS before forwarding through its outbound tunnel. Never expose ports such as 8080 directly through router port forwarding. Public hostnames require passwords of at least 12 characters, and repeated failed sign-ins are temporarily blocked.

Information stored on the phone

Site names, selected folder URIs, ports, upload preferences, hostnames, and site passwords are stored in the app’s private Android preferences. If Cloudflare is enabled, its Account ID, Zone ID, tunnel metadata, and managed hostnames are also stored privately. Cloudflare API and tunnel tokens are encrypted with an AES-GCM key held by Android Keystore. App backup and device transfer are disabled.

Cloudflare configuration traffic

When you enable Cloudflare, Pocket Server sends the Account ID, Zone ID, API token, tunnel configuration, and requested DNS hostnames to Cloudflare’s API. The app creates a dedicated tunnel and manages only CNAME records that target that tunnel. It refuses to overwrite a conflicting DNS record.

Removing access

Stop the server to end network access immediately. Clear the app’s storage or uninstall it to remove stored settings and Android’s persisted folder permission.
